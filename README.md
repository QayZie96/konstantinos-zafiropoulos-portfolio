# Konstantinos Zafiropoulos — Portfolio

A static personal portfolio built with Astro and deployed through Netlify.

## Development

```sh
pnpm install
pnpm dev
```

## Production

```sh
pnpm build
```

The built site is written to `dist/`. The `main` branch is the production branch; use feature branches for meaningful changes so Netlify can provide a preview before merging.
